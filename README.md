## 属于自制内容的部分

下面这些**不是教材内容**，是后来自行编写的：

- 每个词的例句与中文译文（教材词表只有「单词 + 释义」，没有例句）
- 语法条目的讲解文字和例句（教材只给了条目）
- 课文的中文译文、填空与排序游戏
- 情境句练习（动词变位 / 名词阴阳性 / 形容词阴阳性）全部句子
- 界面、图标，以及用 Piper（`fr_FR-siwis-medium`）离线合成的法语语音

其中**例句、练习题按 A1–B2 水平自行编写，不是教材原文**；
**音频也不是教材配套录音**。
